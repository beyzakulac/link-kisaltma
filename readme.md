# Link Kısaltma Projesi

Bu proje, kullanıcıların uzun URL'leri daha kısa ve paylaşılabilir linklere dönüştürmesini sağlayan basit, hızlı ve kullanıcı dostu bir web uygulamasıdır. Kullanılan linkler tarayıcının `localStorage` özelliğinde saklanır, böylece sayfayı yenileseniz bile geçmişteki linklerinize erişebilirsiniz.

##  Kullanılan Teknolojiler

* **HTML5:** Arayüz yapısının oluşturulması.
* **CSS3:** Tasarım ve stil düzenlemeleri.
* **JavaScript (ES6+):** Link kısaltma mantığı, DOM manipülasyonu ve API yönetimi.
* **Fetch API:** URL kısaltma servisi ile iletişim.
* **LocalStorage:** Kullanıcı verilerinin (geçmiş linkler) tarayıcıda tutulması.
* **Font Awesome:** Arayüz ikonları.

##  Temel Özellikler

* **Hızlı Kısaltma:** `shrtco.de` API'sini kullanarak saniyeler içinde link kısaltma.
* **Veri Kalıcılığı:** Kısaltılan tüm linkler tarayıcıda saklanır, kaybolmaz.
* **Kopyalama:** Tek tıkla kısa linki panoya kopyalama özelliği.
* **Silme:** Geçmişinizdeki linkleri kolayca listeden temizleme.
* **Responsive Tasarım:** Mobil ve masaüstü cihazlarla tam uyumlu yapı.
